================================================================================
                              4. خطوات Preprocessing
================================================================================

Pipeline الكامل:
--------------------------------------------------------------------------------
Raw Text
    ↓
1. Remove HTML tags (BeautifulSoup)
    ↓
2. Normalize contractions (can't → can not)
    ↓
3. Lowercase (كل الحروف صغيرة)
    ↓
4. Remove punctuation (علامات الترقيم → مسافات)
    ↓
5. Tokenization (word_tokenize)
    ↓
6. POS Tagging (pos_tag)
    ↓
7. Remove stopwords (مع حماية النفي: not, no, never...)
    ↓
8. Lemmatization (POS-based: running → run)
    ↓
9. Negation Prefix (not enjoy → not_enjoy) — اختياري
    ↓
Clean Text
--------------------------------------------------------------------------------


تفاصيل كل خطوة:
================================================================================

4.1. Remove HTML
--------------------------------------------------------------------------------
الاستخدام: إزالة وسوم HTML زي <br /> من الـ Reviews.

الكود:
    from bs4 import BeautifulSoup
    def remove_html(text):
        return BeautifulSoup(str(text), "html.parser").get_text(" ")

مثال:
    قبل:  "Great movie!<br /><br />Loved it!"
    بعد:  "Great movie! Loved it!"


4.2. Normalize Contractions
--------------------------------------------------------------------------------
الاستخدام: تحويل الاختصارات لكلمات كاملة.

الكود:
    import re
    def normalize_contractions(text):
        text = text.lower()
        text = re.sub(r"\bcan't\b", "can not", text)
        text = re.sub(r"\bwon't\b", "will not", text)
        text = re.sub(r"\bshan't\b", "shall not", text)
        text = re.sub(r"n't\b", " not", text)
        return text

مثال:
    قبل:  "I can't believe it's not better."
    بعد:  "i can not believe it's not better."


4.3. Lowercase
--------------------------------------------------------------------------------
الاستخدام: تحويل كل الحروف لصغيرة.

الكود:
    df["review"] = df["review"].str.lower()

مثال:
    قبل:  "AMAZING Movie"
    بعد:  "amazing movie"


4.4. Remove Punctuation
--------------------------------------------------------------------------------
الاستخدام: تحويل علامات الترقيم لمسافات.

الكود:
    import string
    def remove_punctuation(text):
        return text.translate(
            str.maketrans(
                string.punctuation,
                " " * len(string.punctuation)
            )
        )

مثال:
    قبل:  "Amazing! Great, wonderful."
    بعد:  "Amazing  Great  wonderful "


4.5. Tokenization
--------------------------------------------------------------------------------
الاستخدام: تقسيم النص لكلمات.

الكود:
    from nltk.tokenize import word_tokenize
    tokens = word_tokenize(text)

مثال:
    قبل:  "I loved this movie"
    بعد:  ["I", "loved", "this", "movie"]


4.6. POS Tagging
--------------------------------------------------------------------------------
الاستخدام: تحديد نوع كل كلمة (اسم، فعل، صفة...).

الكود:
    from nltk import pos_tag
    tagged_tokens = pos_tag(tokens)

مثال:
    قبل:  ["I", "loved", "this", "movie"]
    بعد:  [("I", "PRP"), ("loved", "VBD"), ("this", "DT"), ("movie", "NN")]


4.7. Remove Stopwords (مع حماية النفي)
--------------------------------------------------------------------------------
الاستخدام: شيل الكلمات الشائعة مع الحفاظ على كلمات النفي.

الكود:
    from nltk.corpus import stopwords
    stop_words = set(stopwords.words("english"))
    # حماية كلمات النفي (مهم جداً!)
    stop_words -= {"no", "nor", "not", "never", "neither"}

مثال:
    قبل:  ["this", "movie", "was", "not", "good"]
    بعد:  ["movie", "not", "good"]
    لاحظي: "not" اتحفظت!


4.8. Lemmatization (POS-based)
--------------------------------------------------------------------------------
الاستخدام: إرجاع كل كلمة لأصلها حسب نوعها.

الكود:
    from nltk.corpus import wordnet
    from nltk.stem import WordNetLemmatizer

    lemmatizer = WordNetLemmatizer()

    def get_wordnet_pos(tag):
        if tag.startswith("J"):
            return wordnet.ADJ
        elif tag.startswith("V"):
            return wordnet.VERB
        elif tag.startswith("R"):
            return wordnet.ADV
        return wordnet.NOUN

    lemma = lemmatizer.lemmatize(word, get_wordnet_pos(tag))

مثال:
    قبل:  "running", "better", "mice"
    بعد:  "run", "good", "mouse"


4.9. Negation Prefix (اختياري - تحسين)
--------------------------------------------------------------------------------
الاستخدام: لزق كلمات النفي بالكلمة اللي بعدها.

الكود:
    def handle_negation(text):
        negation_words = {
            "not", "no", "never", "neither", "nor",
            "cannot", "cant", "wont", "dont", "didnt",
            "isnt", "arent", "wasnt", "werent",
            "hasnt", "havent", "hadnt",
            "wouldnt", "shouldnt", "couldnt"
        }
        tokens = text.split()
        result = []
        i = 0
        while i < len(tokens):
            word = tokens[i]
            if word in negation_words and i + 1 < len(tokens):
                combined = f"{word}_{tokens[i + 1]}"
                result.append(combined)
                i += 2
            else:
                result.append(word)
                i += 1
        return " ".join(result)

مثال:
    قبل:  "not enjoy"
    بعد:  "not_enjoy"

        X, y,
        test_size=0.2,
        random_state=42,
        stratify=y
    )
    النسبة: 80% تدريب / 20% اختبار


5.4. TF-IDF Vectorization:
    from sklearn.feature_extraction.text import TfidfVectorizer
    vectorizer = TfidfVectorizer(
        max_features=20000,
        ngram_range=(1, 2),
        min_df=2,
        max_df=0.95,
        sublinear_tf=True
    )
    X_train_tfidf = vectorizer.fit_transform(X_train)
    X_test_tfidf = vectorizer.transform(X_test)

    شرح Parameters:
    ----------------------------------------
    max_features = 20000    → أشهر 20,000 كلمة
    ngram_range = (1, 2)    → كلمة + كلمتين مع بعض
    min_df = 2              → نتجاهل الكلمات اللي ظهرت أقل من مرتين
    max_df = 0.95           → نتجاهل الكلمات اللي ظهرت في > 95%
    sublinear_tf = True     → تحسين رياضي
    ----------------------------------------


5.5. Logistic Regression:
    from sklearn.linear_model import LogisticRegression
    model = LogisticRegression(
        max_iter=1000,
        C=1.0,
        solver='liblinear',
        random_state=42
    )
    model.fit(X_train_tfidf, y_train)


5.6. التقييم:
    from sklearn.metrics import (
        accuracy_score, precision_score,
        recall_score, f1_score
    )
    y_pred = model.predict(X_test_tfidf)
    print(f"Accuracy :  {accuracy_score(y_test, y_pred):.4f}")
    print(f"Precision:  {precision_score(y_test, y_pred):.4f}")
    print(f"Recall   :  {recall_score(y_test, y_pred):.4f}")
    print(f"F1-Score :  {f1_score(y_test, y_pred):.4f}")
