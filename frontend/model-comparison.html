01 · THE PROJECT

Project Overview

Turning thousands of movie opinions into meaningful sentiment insights.

THE CHALLENGE

What are we solving?

Movie reviews contain valuable opinions about stories, acting, direction, and the overall viewing experience. Reading and classifying a large number of reviews manually is time-consuming.

MovieMind applies Natural Language Processing and sentiment classification to determine whether a written review expresses a positive or negative opinion.

03 · THE EXPERIMENTS

Five Models. One Evaluation Set.

Different ways of representing language and learning sentiment patterns.

MODEL 01

svm

A Support Vector Machine-based approach used as a strong traditional machine-learning baseline for text classification.

Traditional Machine Learning
MODEL 02

Word2Vec

Represents words as dense vectors that capture semantic relationships, then uses a LinearSVC classifier for sentiment prediction.

Word Embeddings + LinearSVC Used in the MovieMind application
MODEL 03

LSTM

A recurrent neural network architecture designed to learn patterns and dependencies across sequences of words.

Deep Learning · Sequence Model
MODEL 04

FastText

Uses word representations built from character n-grams, helping the model learn information from subword units.

Subword Embeddings
MODEL 05

ELMo

Uses deep contextualized word representations, where a word's representation is influenced by its surrounding context.

Contextual Language Representation

Deployment note: The highest score in the research comparison is not automatically the model used by the application. MovieMind's integrated sentiment model is Word2Vec + LinearSVC.

06 · CONCLUSION

What the Results Tell Us

RESEARCH FINDING

svm achieved the highest F1-score

Among the five evaluated approaches, svm ranked first with an F1-score of 90.2101% and a ROC-AUC of 96.5407%. Word2Vec ranked second with an F1-score of 88.2447%.

The results show why model selection should consider more than one metric: predictive performance, training cost, inference speed, and the requirements of the final application all matter.

APPLICATION MODEL

Word2Vec + LinearSVC

This is the model integrated into MovieMind. The research comparison and the deployed application model serve two different purposes: one reports the best measured score, while the other reflects the model selected for the application.
