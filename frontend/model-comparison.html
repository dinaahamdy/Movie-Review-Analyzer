01 · THE PROJECT

Project Overview

What are we solving?

Movie reviews contain valuable opinions, but manually reading thousands of reviews is time-consuming. This project applies NLP and sentiment classification to identify whether a review expresses a positive or negative opinion.

The study compares a TF-IDF-based baseline with sequence-based and contextual language representations.

Dataset

IMDb

Movie-review text with positive and negative sentiment labels. The exact sample counts used in training will be loaded from the experiment results.

03 · THE MODELS

Three NLP Approaches

MODEL 01 · BASELINE

TF-IDF + Linear SVM

Represents a review as weighted word and phrase features, then uses a linear Support Vector Machine classifier. This is the current training approach found in the project code.

  • Sparse lexical features
  • Fast training and inference
  • Does not explicitly model word order
MODEL 02 · DEEP LEARNING

LSTM

Uses token embeddings and recurrent memory to learn patterns across word sequences in a review.

  • Sequence-aware representation
  • Captures order and longer dependencies
  • Requires tokenization and padding
MODEL 03 · CONTEXTUAL NLP

ELMo + Classifier

Uses pretrained contextual word representations. A word's vector depends on the surrounding sentence context, then a classifier predicts sentiment.

  • Context-dependent embeddings
  • Pretrained language representation
  • Higher setup and compute requirements

Important: ELMo is itself based on a bidirectional language-model LSTM. In this comparison, “LSTM” means a task-trained sequence classifier, while “ELMo” means pretrained contextual embeddings followed by a sentiment classifier.
